# AUV 데이터 수집 대시보드

ROS 2 Humble 데스크톱에서 사용하는 Tkinter 프로그램입니다. 대시보드 코드와 문서는
이 폴더에 있으며, 기존 수집기와 exporter를 그대로 호출합니다.

## 실행

ROS와 메시지 패키지를 빌드한 워크스페이스의 환경을 먼저 불러옵니다.
`auv_dvl_a50_msg`, `mavros_msgs`, OpenCV, Tkinter가 필요합니다.

```bash
sudo apt install python3-tk
source /opt/ros/humble/setup.bash
source /path/to/auv_ros2/install/setup.bash
cd /path/to/auv_vla_dataset_maker
python3 -m dashboard
```

패키지를 다시 colcon 빌드한 경우에는 다음 명령도 가능합니다.

```bash
ros2 run kmu26_auv_vla_data_collector dashboard
```

화면이 있는 데스크톱 세션에서 실행하세요. SSH에서는 GUI 표시 환경이 필요합니다.
대시보드는 Python 3.10/ROS 환경에서, 내보내기는 Python 3.12 가상환경에서 실행합니다.

## 수집 순서

1. 설정 YAML, staging 폴더, 시뮬레이션 시간 사용 여부를 설정합니다.
2. **수집기 실행**을 누르고 로그에서 기동을 확인합니다. 이미 터미널에서 실행한
   수집기도 사용할 수 있으며, 이 경우 대시보드에서 다시 실행하지 않습니다.
3. **ROS 연결 / 다시 연결**을 누릅니다. 수집기의 실제 파라미터에서 토픽, 시간 기준,
   staging 경로를 읽습니다. 이름을 변경했다면 수집기 노드 필드를 수정하세요.
4. 두 카메라 영상과 센서 수신 상태를 확인합니다. age는 수신 age와 ROS 헤더의 원본
   age를 표시합니다. Hz는 최근 수신 기준입니다. DVL은 선택 입력입니다.
5. 영어 작업 설명을 입력하고 **전송**, 이후 **시작**을 누릅니다.
6. 수행 결과에 따라 **성공 저장** 또는 **실패 저장**을 누릅니다. 필요하지 않은 현재
   에피소드는 **폐기**합니다. 폐기는 확인 창 이후 실제 수집기 데이터를 삭제합니다.

상단 통계와 저장 목록은 2초마다 staging의 manifest를 읽습니다.
`.recording_episode_*`는 진행 중인 수집 또는 중단된 임시 폴더일 수 있습니다.
수신의 최신 여부만으로 시작 가능성을 확정하지 않습니다. 좌표계, RC 소유권,
작업 설명 등은 수집기의 시작 서비스가 최종 검증합니다. 별도 녹화 상태 토픽이
없으므로 상단 상태는 파일 시스템 관찰이며 서비스 응답과 로그도 함께 확인하세요.
카메라 미리보기는 수신 영상을 최대 480×180에 맞춰 표시합니다.

대시보드가 실행한 수집기만 **수집기 종료** 버튼으로 종료할 수 있습니다.
SIGINT로 정상 종료를 요청하고 저장이 완료될 때까지 기다립니다. 수집 중이었다면
기존 수집기의 정책대로 프레임이 있는 데이터는 `success=false`,
`termination_reason=node_shutdown`으로 저장됩니다. 외부에서 실행한 수집기는
원래 터미널에서 종료하세요. 서비스 응답이 시간 초과되면 요청이 실제 처리되었을
수 있으므로 다시 누르기 전에 로그와 폴더를 확인하세요.

## LeRobot v3 내보내기

기존 README대로 별도 Python 3.12 환경에 `requirements-export.txt`를 설치합니다.
**LeRobot v3 내보내기** 탭의 Python 실행 파일에 그 환경의 `bin/python`을 지정합니다.

- 입력 staging은 수집 화면과 공통입니다. 수집을 저장/종료한 뒤 변환합니다.
- 출력은 아직 존재하지 않는 새 폴더 경로를 입력합니다.
- 데이터셋 ID는 `your-hf-user/kmu26-auv-real` 같은 로컬 식별자입니다.
- 성공/실패 에피소드를 모두 내보냅니다. 자동 Hugging Face 업로드는 하지 않습니다.
- 변환 도중 화면과 로그는 계속 사용할 수 있습니다.
- 중단하면 부분 출력이 남을 수 있습니다. 이후에는 새 출력 경로로 다시 실행하세요.
- 체크아웃 실행 시 현재 소스의 exporter를 호출합니다. 설치된 대시보드에서는 선택한
  Python 환경에도 이 프로젝트가 설치되어 있어야 합니다.

## 검증

```bash
python3 -m pytest -q dashboard/test_backend.py
python3 -m dashboard --help
```

백엔드 테스트는 ROS나 화면 없이 파일 조회, 인자 검증, 프로세스 출력과 정상 종료를
검사합니다. 실제 차량의 ROS 메시지와 센서를 연결한 수집/저장/변환은 해당 환경에서
확인해야 합니다.
